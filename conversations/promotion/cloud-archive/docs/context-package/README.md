# 人生管理系统 4.0

## 项目目标

构建一个以用户目标、价值与边界为上层约束，以“人生总控”协调多个生活领域，以证据、决策流程、行动执行和反馈更新为运行闭环的个人管理系统。系统不是简单的待办清单、日记或咨询机器人，而是帮助用户持续协调目标、资源、承诺、风险和行动的个人决策与控制平台。

## 产品定位

长期定位：个人目标的持续协调平台。系统面向真实生活中的多目标冲突，例如职业转型、学习、家庭承诺、健康、财务与休息之间的协调。

首发验证场景：在职职业转型。早期不要求用户填完全部人生领域，只需目标、可用时间、现有承诺和必要的约束即可启动。

## 核心设计

- 1 个总控：维护目标、边界、全局快照、共同资源、优先级和跨领域影响。
- 9 个人生领域：健康恢复、心理调节、关系家庭、职业劳动、学习能力、财务保障、居住日常、社群责任、休闲审美。
- 23 个共享能力模块：逻辑、认识论、科学方法、统计、数学、数据、决策、运筹、经济、博弈、心理、伦理、系统科学、控制论、系统工程、历史思想、社会制度、管理、沟通谈判、法律财务健康、英语检索、计算机自动化与 AI 等能力按问题调用，而不是各自独立管理人生。
- S1—S8 决策引擎：定义问题、建立事实、生成方案、约束与比较、反驳与复核、建议与取舍、授权执行、反馈更新。
- 主动服务：读取已授权数据，发现关键缺口时主动补问；证据足够时提出建议；冲突、敏感数据或数据新鲜度不足时要求确认。

## 核心原则

硬约束先于综合评分；共同资源只计一次；缺失值不能默认填零；精力和情绪作为状态与边界，不随意折算为资金分值；影响关系要标明来源；建议、用户选择、实际执行必须分开记录；没有执行记录时写“执行情况未知”；目标、证据或方案变化后重新检查旧结论。
