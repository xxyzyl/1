# 升级到决策规则 2.0

本次增加原始能力要求、23领域方法地图、可靠资料索引、执行协议、复核清单和结构检查工具。这些文件不自动修改你电脑上的项目或 Codex 全局设置。

## 旧项目已有个人记录

把新版解压到另一个目录，让自己的 Codex 对照合并。保留已有自定义规则；遇到真正冲突再询问，已授权的可恢复整理直接做。

可对 Codex 说：

> 请对照我提供的新旧人生管理项目，升级到决策规则2.0。新增 CAPABILITY_BRIEF.md、METHODS.md、RESOURCES.md、RESEARCH/、DECISION_PROTOCOL.md、REVIEW_CHECKLIST.md、GLOBAL_ENTRYPOINT.md、scripts/check_decision.py 和 EXAMPLES/。合并 AGENTS.md、WORKFLOWS.md、START_HERE.md、README.md、CHANGELOG.md、TEMPLATES/decision.md 和 TEMPLATES/weekly.md，保留我已有的自定义规则。保留旧项目全部个人资料、目标、行动和真实历史记录，不用新版空白文件覆盖它们。已有同名方法文件或脚本先比较再合并。最后报告实际变更、冲突和验证结果。EXAMPLES 都是合成案例，不是我的个人信息。

尤其保留 `NOW.md`、`PROFILE.md`、`GOALS.md`、`ACTIONS.md`、`INBOX.md`、`AREAS.md`、`LEARNING.md`，以及 `PROJECTS/`、`DECISIONS/`、`REVIEWS/` 中的真实记录与索引。不要把整个新版解压覆盖已使用的目录。

新增的 `LEARNING_AND_EVALUATION.md` 和 `VALIDATION.md` 也一并合并；后者仅说明发布包的检查，不代表旧项目升级后的实际验证。升级后仍需检查本地结果。

## 首次使用

直接从完整新版项目启动，按 START_HERE.md 初始化。未知个人情况仍为空。

## 验证与生效范围

重新启动项目对话，要求 Codex 实际读取协议与方法，指出版本、基础检查、按需方法和补证规则。使用 EXAMPLES 的合成案例运行结构检查，再提供一个低影响的真实选择观察输出。

项目规则在正确打开项目并成功加载时作用于该项目。跨项目使用可以按 GLOBAL_ENTRYPOINT.md 配置入口；本包没有自动设置全局规则，也不保证其他客户端、账号或未来会话自动获得这些文件。
