## 1. 问题、目标与约束

假设一名学习者打算用两个小时练习清洗一份练习数据，希望能够标出重复记录、统一日期并检查缺失值。硬约束是总用时不超过两小时、不购买工具。是否已具备基础尚未知。本例不安排真实日期或提醒。

## 4. 方案与取舍

方案A：用两小时阅读相关教程，可能补齐知识，但未安排完整的产物检验。方案B：20分钟尝试小样本，60分钟清洗，30分钟核对结果，10分钟记录错误；合计20+60+30+10=120分钟。方案C：暂缓学习，保留时间，不能在本轮检验所需能力。

三者在时间和费用约束内。只有B明确分配了检查实际产物的时间，但不据此声称B必然学得最好。没有真实效果数据，因此不打收益分数、不估计成功率。

## 5. 反对理由与敏感性

最强反对理由：若基础不足，直接做任务可能持续卡住，B的后续安排不可执行。反转条件是前20分钟无法完成最小样本中的基本操作，且无法理解错误原因；此时把剩余时间改为针对该障碍的讲解和示范，不要求硬撑完成整份数据。该阈值是演示设计，不是普遍教育规律。

## 6. 建议、条件与下一步

在具备最基本操作能力的假设下，先试B的前20分钟，再据实际情况调整。完成标志是能展示重复处理前后、日期统一结果和缺失值标记，并解释一个处理选择。到两小时停止，记录未完成部分。用户尚未作出真实选择，不生成实际任务。
