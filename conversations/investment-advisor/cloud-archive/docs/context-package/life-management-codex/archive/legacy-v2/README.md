# Codex 人生管理系统｜决策规则 2.0

这是包含23个学科方法模块、资料索引和决策执行规则的项目文件。旧版用户请先看 `UPGRADE.md`，保留已有个人记录后合并更新。

这是一套可以交给你自己的 Codex 使用的项目文件。你提供现实情况与目标，Codex 负责整理记录、比较选择、拆解行动和复盘。文件保存长期上下文；你的决定与行动产生反馈。

## 现在开始

1. 将压缩包解压到你电脑上固定使用的文件夹，保留 `life-management` 目录。
2. 在支持本地项目的桌面客户端中打开这个目录；使用 VS Code 时，打开同一目录并使用 Codex 扩展；使用已经安装好的 Codex CLI 时，在该目录的终端输入 `codex`。请在包含 `AGENTS.md` 的目录启动新对话。此文件包不安装 Codex。
3. 对 Codex 说：**请读取 AGENTS.md、README.md 和 START_HERE.md，按照 START_HERE.md 带我初始化这套人生管理系统。**

你不用一次填完所有文件。先明确一个现实问题、一个近期目标和一个下一步行动。时区、时间预算、收入、家庭责任等未知信息都保留为空；需要用到时再补。

## 日常怎么用

每天方便时说几句话即可，例如：今天做了什么；哪里卡住了；接下来准备做什么。让 Codex 整理进 `INBOX.md`，再把有用信息关联到目标或行动。记录中的缺失表示“未知”，不表示“没有做”。

每周让 Codex 根据这一周的真实记录生成复盘：出现了什么成果；哪个判断需要修正；什么行动值得继续；下周最重要的一个调整是什么。记录不足时只做有依据的部分。

遇到重要选择时，让 Codex 创建决策记录：问题、目标、约束、备选方案、证据、未知、可逆尝试、建议以及改变建议的条件。决定前保留原始依据，之后追加实际结果。

## 怎样判断它有没有用

试用两周后，检查是否更容易找到以前的信息、是否推进了一个真实问题、记录是否足够省力。如果维护花费超过收益，就删减字段和流程。工作、学习、健康、关系、休息都可以成为目标；不设统一“人生总分”。

## 自动化与访问边界

起步版通过你主动输入和提供文件获得数据，没有自动采集电脑操作的程序。以后可以按实际需要接入可用且已授权的数据来源。

本文件包没有在你的电脑上运行，也没有替你创建本地定时任务。本次对话已有的“每周复盘学习成果”是提醒，不会自动读取这个本地目录。详见 `AUTOMATION.md`。

将资料存在本地，不等于处理过程完全离线。交给联网模型分析前，只保留完成任务所需的信息，敏感原件可留在项目之外。按自己的设备条件定期做加密备份；备份完成需验证可恢复。

## 官方功能依据

功能核对日期：2026-09-05。客户端入口和可用性可能随版本、账号与工作区设置变化。

- [OpenAI 官方文档：AGENTS.md](https://learn.chatgpt.com/docs/agent-configuration/agents-md)：说明项目规则的读取和作用范围。本项目其他文件需要通过规则明确要求读取，不假定全部自动加载。
- [OpenAI 官方文档：定时任务](https://learn.chatgpt.com/docs/automations)：说明网页与本地项目任务的区别。需要本地文件的桌面任务要求电脑开机且应用运行；CLI 与 IDE 扩展没有 Scheduled 管理界面。

本项目的模块、模板、工作流程是为本次需求设计的建议，不是 OpenAI 内置的“人生管理”产品功能。

## 2.0版本怎样使用这些能力

每次决策都检查目标、证据、约束、备选、反对理由、不确定性与反馈。根据问题选择实际相关的学科方法，每项都要有输入和可检查产物。重要决策保留完整记录，并进行证据核验、必要计算和复核。

“严格”指不跳过必要的检查、不隐瞒关键未知、不把书目或模型自信当证据。日常易撤回的小事可用简版，重大问题展开完整流程。具体模型和原始资料须符合场景，不能机械叠加全部23种方法。

资料库含原创整理、公开来源链接和查阅记录，没有打包受版权保护的整本教材。各领域都有核心资料入口，但不代表逐条子概念的教材都已精读、课程都已完成或所有专业结论都能独立解决。待补范围见 RESOURCES 与各研究文件。

检查示例：在项目根目录运行 `python3 scripts/check_decision.py EXAMPLES/example_decision.md`。这只验证格式与少量显式状态，不验证真实决策效果。本包未在你的Codex客户端中完成实际运行验证。
