# 人生管理系统：本地 Codex 工程上下文包

## 项目目标

把个人的价值、目标、现实约束、行动和结果连接起来，形成一个可持续使用的 AI 个人规划与执行系统。系统首先服务“在职职业转型”场景：用户希望在有限业余时间内学习、制作作品、求职，同时保留工作、家庭、健康和缓冲。

## 产品定位

产品形态是“手机文字/语音对话入口 + 网页计划与复盘页”。用户用自然语言说明目标、可用时间和变化，系统只追问会改变下一步的关键信息，生成真实可执行的备选方案，检查跨领域资源冲突，记录用户选择，跟踪执行结果并在条件变化后更新计划。

长期愿景是个人目标的持续协调平台，而不是单纯待办清单、日历或聊天机器人。首发场景、定价、目标人数和融资金额都是待验证假设。

## 核心功能

- 目标、底线、阶段任务与已有承诺管理
- 九个人生领域状态：健康、心理、关系、职业、学习、财务、日常基础、社群责任、休闲体验
- 共同资源账：时间、资金、固定承诺和缓冲只计算一次
- 八阶段决策引擎：定义问题、建立事实、生成方案、约束比较、反驳复核、建议取舍、授权执行、反馈更新
- 对话式补问、来源与更新时间记录、未知标记和用户纠正
- 计划、项目、行动、验收和复盘记录
- 日历/任务/文件连接器（按用户授权逐步接入）
- 人工辅助试点和产品化交付成本统计
- 证据、输入版本、决定版本和变更原因可追溯
