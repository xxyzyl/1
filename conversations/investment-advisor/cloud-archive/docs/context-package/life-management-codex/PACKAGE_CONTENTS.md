# PACKAGE_CONTENTS.md — 包内容说明

本包用于交给本地 Codex 继续开发人生管理系统 4.0。根目录六份文件是当前工程基线；`archive/` 中资料只作为历史上下文。

## 根目录文件

| 文件 | 用途 |
|---|---|
| README.md | 项目目标、产品定位、核心功能和当前进度 |
| AGENTS.md | 本地 Codex 工作规则、代码风格、开发原则和禁止事项 |
| SPEC.md | 系统需求、用户流程、数据结构和接口设想 |
| TODO.md | 下一步开发任务和优先级 |
| ARCHITECTURE.md | 系统架构、模块拆分、数据流和前后端划分 |
| .env.example | 环境变量模板 |
| START_HERE.md | 给本地 Codex 的启动说明和可直接粘贴的任务提示 |

## 目录说明

| 目录 | 文件数 | 说明 |
|---|---:|---|
| archive/ | 73 | 旧版上下文与历史包拆出文件 |
| artifacts/ | 18 | 流程图、PPT、HTML 预览和图数据 |
| context/ | 6 | 当前上下文摘要、原始设计和 PPT 文本抽取 |
| docs/ | 8 | 工程补充说明 |
| examples/ | 2 | 可运行示例输入 |
| methodology/ | 110 | 现行科学决策与人生管理 Skill 源码快照 |
| validation/ | 7 | 验证报告和原始测试输出 |
