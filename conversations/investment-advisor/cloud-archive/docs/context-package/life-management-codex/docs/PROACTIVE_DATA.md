# PROACTIVE_DATA.md — 主动服务与数据连接规则

## 原则

主动服务必须以用户授权为边界。系统可以提醒用户确认新事实、冲突和机会，但不能因为用户曾经说过“你可以主动帮我”就默认读取所有数据或执行所有外部动作。

## 授权维度

每个授权至少包含：数据源、读范围、写范围、用途、有效期、通知渠道、撤销方式。

## MVP 行为

- 默认关闭全部连接器。
- 默认只生成站内候选建议。
- 每天最多 3 次主动提醒。
- 默认静默时间 22:00-08:00。
- 用户拒绝某类提醒后进入冷却，不反复打扰。

## 外部动作边界

发送邮件、发送消息、创建日历、修改任务、报名、付款、投递、联系他人，都必须经过明确授权，并在执行前再次检查授权有效。撤销授权后，尚未执行的队列动作必须取消。
