# COMMERCIAL_CONTEXT.md — 商业化上下文

## 当前判断

项目可以向商业化产品发展，但当前材料证明的是方法设计、规则原型和演示资产，尚未证明真实用户留存、付费或融资结果。

首个建议验证场景是“在职职业转型与长期能力成长”。这个场景有明确目标、真实资源冲突和可观察阶段成果，更容易验证系统是否比通用 AI、表格、日历和任务工具提供额外价值。

## 可讲的产品一句话

一个 AI 个人规划助手，帮助正在职业转型的人把学习、作品、接单、求职和已有生活承诺放到同一张资源账里，形成可执行计划，并根据实际进展持续调整。

## 投资人会问的问题

| 问题 | 当前材料能回答什么 | 仍需补证 |
|---|---|---|
| 谁需要它 | 已有职业转型、学习、接单和生活承诺协调的产品假设 | 真实访谈、付费试点、留存 |
| 为什么不用通用 AI | 本系统保存状态、版本、资源账、授权和复核队列 | 与通用 AI + 表格/日历的对比试验 |
| 是否可规模化 | 规则层和 mock-first 架构可工程化 | 单用户服务成本和自动化比例 |
| 是否有壁垒 | 方法体系、长期状态、数据连接、信任和场景经验 | 真实用户数据和可复制获客 |
| 融资用途 | 可用于完成 MVP、试点、连接器和商业验证 | 团队、预算、里程碑数字 |

## 路演素材

`artifacts/presentations/人生管理系统-投资人路演.pptx` 是历史路演材料。它可作为素材，但本地 Codex 不应把其中假设指标写成已验证事实。演示前应替换为真实用户访谈、试用和付费数据。

## 近期商业验证任务

1. 找 5-10 个在职转型用户访谈。
2. 用人工+原型完成一次真实周计划和复盘。
3. 记录用户愿不愿意付费、付多少钱、是否按建议调整行动。
4. 统计每位用户所需人工时间和模型成本。
5. 把结果更新到路演材料。
