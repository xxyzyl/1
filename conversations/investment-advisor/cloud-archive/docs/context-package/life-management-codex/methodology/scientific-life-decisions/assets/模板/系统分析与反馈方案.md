# 系统分析与反馈方案

按问题复杂度选填；无需为简单可逆事项运行全套数学分析。

- 决策ID、阶段、输入版本：
- 建议状态（待补证/条件建议/建议可供选择）：
- 用户选择（未知/未决定/已决定/暂缓）：
- 执行状态（未知/未开始/执行中/已暂停/已完成/已停止）：

## 目标、整体与边界

- 想改善的实际结果及期限：
- 硬约束、资源总量、不能牺牲的价值：
- 系统包含什么、边界外是什么、有哪些自主参与者：
- 子系统、接口、负责人及局部优化可能损害的整体：

- 存量、流入、流出及反馈：

- 当前基线及暂不改变方案：
- 硬约束检查、尚未显现的累计投入：
- 最强反例；参数、延迟或环境变化何时使建议反转：
- 数学保证/有限仿真/定性判断分别是什么；不能声称什么：
- 用户已有授权范围、谁负责、实际下一步：
- 停止或降低投入条件；有害信号即时处理方式：
- 下一次评价时间、为何足以看到相关结果；何时只记录而不改策略：

## 反馈更新

- 原预测及依据 → 实际观察 → 差异：
- 测量、机制、执行、环境四类解释及证据：
- 继续/调整/停止的理由；目标、参数、策略或模型结构改了什么：
- 新输入版本及需要重做的比较与复核：
