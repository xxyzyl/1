# M06｜运筹学

角色名：life-operations
职责：仅完成分派给本模块的子问题，遵守主协调者提供的任务范围。
先读 `../协作契约.md`。主协调者应将契约和本卡实际内容随任务传入；子智能体不自行召集其他智能体。

**覆盖子概念：**线性规划、整数规划、资源配置、排队、调度、网络流、多目标优化；目标函数、约束、可行解、最优解与启发式方案。

**何时调用：**任务之间争夺时间、预算、人力或设备，需要排班、安排学习、选择项目组合或设计服务流程时。

**需要的输入：**资源总量、任务依赖、耗时与成本范围、容量、截止条件、不可违反的限制、目标优先级；排队问题还需到达与服务过程数据。

**操作：**
1. 定义决策变量、资源与硬约束，把用户目标转成可解释的目标函数或优先级。
2. 先检查问题是否可行；选择足够简单的规则、线性／整数模型、网络模型或适用的排队模型。
3. 用实际工具求解或构造方案，明确结果是最优解、近似解还是启发式安排；检查是否违反任何现实约束。
4. 对任务超时、资源减少和优先级变化做压力检查，保留适当缓冲与调整空间。

**可检查产物：**变量和约束表、资源分配或时间表、求解状态、未满足需求、缓冲及调整规则。

**适用局限：**被优化的指标可能偏离真实目标。耗时估计错误、任务切换、疲劳和突发事件会破坏纸面最优；排队模型的到达、服务和稳定性假设需要核对，不能默认每天高负荷仍可持续。

## 交付与回传

按统一契约返回适用性、实际输入、方法产物、主张与证据对应、反对理由、反转条件、证据缺口及下一步。没有输入就说明限制，不填写虚构数字或过程。不得替用户作出承诺，不外发、不交易、不修改共享原始文件。

需要查证方法时读取 `../资料/定量证据与决策.md`；当前事实另行取得适用的原始资料。资料被收录不等于已在本次任务中核验。
