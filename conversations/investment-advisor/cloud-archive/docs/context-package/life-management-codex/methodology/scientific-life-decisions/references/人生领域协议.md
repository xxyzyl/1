# 人生领域协作协议

适用于D01—D09。领域是生活结果的维护范围，M01—M23是共享知识与方法。总控由主协调者承担；领域执行者不递归派工、不自行改写全局记录，统一协作契约仍适用。

## 输入

接收具体问题、当前S阶段和决定版本、全局快照ID及版本、用户目标和底线、已有事实/假设/未知、共同资源范围、主责及受影响领域、允许行动。缺失输入如实标出；不自行补用户履历、预算或关系信息。

## 工作

1. 确认所维护的实际结果；区分状态、观测指标、主观体验、假设和外部扰动。不把某领域指标当作整个人生目标。
2. 给出实际选项及机制；标记自己能干预什么、哪些需要其他人的自主配合、效果何时可能出现。
3. 返回时间、资金、前置任务、缓冲与无法数值化的负荷需求；与共同资源账同一周期和单位。不能擅自承诺跨领域资源。
4. 一件事项只使用一个全局行动ID和一个主责领域；其他领域引用其影响，不复制记账或重复执行。
5. 给出最强反对理由、可能受损的其他领域、证据缺口、退出方式和观察窗口。发现跨域冲突，回传总控协调，不投票压过用户底线。
6. 按问题调用已有M模块方法；需要额外工作时向主协调者提出具体子任务，不自行创建代理。

## 回传

- 当前任务ID、全局快照ID/版本、决定ID/阶段/版本、领域及实际适用性；
- 事实与来源、状态与代理指标、关键未知；
- 主责行动ID、关联目标、备选与资源需求；
- 受影响领域、作用方向、延迟、证据或假设、前置依赖；
- 不可补偿的约束、反对理由、条件建议、反馈与停止条件；
- 实际做了什么及未做什么。建议状态、用户选择和执行状态分开。

只传任务所需信息；健康、关系和财务等个人原始数据不写入通用Skill。领域名不赋予专业资格或对用户生活的控制权。
