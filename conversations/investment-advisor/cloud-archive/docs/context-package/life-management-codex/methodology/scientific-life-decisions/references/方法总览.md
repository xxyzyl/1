# 跨学科方法库

版本：2.0  
编制日期：2026-09-05  
用途：把用户提出的能力体系转化为可调用、可检查、可修正的决策方法。

本文件保存方法及使用边界；资料入口、来源状态和研究记录详见 `资料索引.md` 与 `资料/`。涉及当前事实、法律、医疗、金融、软件版本或有争议的具体主张，调用时仍须核对适用地区、日期和原始资料。只有名称、链接、书目或检索摘要，不等于已经取得、读懂或验证了资料。

## 使用规则

所有决策都做 M01 的事实与推理检查、M05 的目标与选项检查，以及 M23 的伦理与价值检查；日常小事可以各用一句话完成，重要决定按 `决策协议.md` 展开。纯粹抄录、排版和文件整理无需伪装成重大决策。

其他方法按问题实际需要调用。先写明“采用的编号、要解决的子问题、适用条件”，再执行对应步骤；不要求把 23 个领域全部套用一遍。与结论有关却缺少输入的方法，记录缺失及影响，不填造数据。不同方法给出相反建议时，说明它们的假设、目标或证据为何不同，不能通过简单投票消除冲突。

每项方法的输出都应能回到现实材料、可复现计算或明确标注的用户价值偏好。书目齐全、规则写入 Markdown、模型能复述概念、代理审查通过，都不能证明掌握了方法，也不能保证结论科学准确。检验依靠具体任务表现、真实证据、必要的外部核实与后续结果。

## M01｜逻辑、认识论与科学方法

**覆盖子概念：**命题与论证；必要条件与充分条件；归纳与演绎；相关与因果；反例；常见逻辑谬误；证据等级与研究设计；可证伪性；观察、选择和测量偏差；可靠结论的形成与修正。

**何时调用：**所有决策；尤其是比较相互冲突的说法、检查宣传或专家意见、从少量经历推出一般结论时。

**需要的输入：**待判断的具体主张、原始材料、来源日期、支持理由、反对材料、用户实际观察，以及尚未核实的前提。

**操作：**
1. 把问题改写成明确命题；分开事实、用户陈述、假设、价值判断与建议，列出论证依赖的前提。
2. 检查必要条件是否被误当充分条件、个例是否被过度推广、相关是否被当因果，以及循环论证、偷换概念等错误。
3. 核对证据是否直接支持主张，主动找反例和竞争解释，说明什么观察会削弱或推翻判断。
4. 给出与证据强度相称的结论、适用范围和关键未知；重要未知转为可执行的核实任务。

**可检查产物：**主张—前提—证据对应表；最强反对理由；已知／假设／未知标记；会改变结论的证据清单。

**适用局限：**推理有效不代表前提真实。证据质量不能只按单一“等级表”排序，还取决于研究问题、执行质量和适用人群；模型自述“已验证”不构成验证。

## M02｜基础数学

**覆盖子概念：**代数、方程与不等式；函数；指数与对数；集合；向量与矩阵；微积分的变化率、边际量与累积思想。

**何时调用：**需要表达数量关系、增长或衰减、复利、资源约束、比较量级，以及建立统计或优化模型时。

**需要的输入：**变量定义、单位、时间尺度、可用数值及来源、变量取值范围、关系假设与待求量。

**操作：**
1. 定义变量、单位、边界和方程，区分绝对值、比例、百分点、平均量与边际量。
2. 选择满足需要的最简单表示；仅在线性关系合理时用线性模型，仅在相应条件成立时用指数或微积分模型。
3. 使用可复现的公式或代码计算；检查量纲、极端情况、数量级和舍入影响，必要时用另一种计算方式核对。

**可检查产物：**变量与单位表、关系式、输入来源、可复现计算、边界及量级检查结果。

**适用局限：**计算正确不能弥补模型设定错误；不把未经验证的现实关系强行写成精确公式，不以多位小数掩盖输入不确定性。

## M03｜概率论与统计学

**覆盖子概念：**条件概率、贝叶斯公式、随机变量、期望、方差、常见分布、大数定律、中心极限定理；抽样、置信区间、假设检验、回归；实验设计与因果推断的接口见 M04。

**何时调用：**从样本推断总体、比较风险和波动、更新判断、分析调查或行为记录、评价预测表现时。

**需要的输入：**总体与样本定义、采样过程、样本量、数据字典、缺失与异常记录、时间结构、基准发生率，以及先验假设的来源。

**操作：**
1. 检查代表性、选择偏差、测量口径、重复记录与缺失机制；先报告样本实际覆盖的范围。
2. 先做分布和描述统计，再选择适当估计、回归或检验；检查独立性、时间依赖、分布与模型假设。
3. 报告效应大小及不确定性，必要时处理多重比较；贝叶斯更新注明先验依据，主观先验需单独标识并检验其影响。
4. 检查结果对样本、异常值和模型设定是否敏感；预测任务使用适合数据结构的留出验证，并与简单基线比较。

**可检查产物：**样本覆盖说明、数据质量摘要、可复现代码或公式、效应与区间、假设检查、验证结果。

**适用局限：**统计显著不等于实际重要；不显著不等于没有效果。经典置信区间不能直接解释为已实现区间中参数的后验概率。大数定律和中心极限定理都有适用条件，样本变大不会自动消除系统偏差；回归本身不能建立因果。

## M04｜因果推断与实验设计

**覆盖子概念：**相关与因果、反事实、混杂、选择偏差、时间先后、实验设计、随机分配、对照、测量、因果图、准实验、因果效应与适用范围。

**何时调用：**要判断培训、习惯、政策、营销或产品改动是否带来变化，或要依据观察数据决定采取某种干预时。

**需要的输入：**目标人群、干预、比较条件、结果指标、时间范围、潜在混杂因素、可获得的干预前后数据、实施限制。

**操作：**
1. 写清“对谁、实施什么、与什么相比、在多久内改变什么”，明确要估计的因果问题。
2. 列出变量关系和可能的混杂、反向因果与选择机制；优先考虑可行且合适的对照设计。
3. 预先确定主要指标、观察周期和分析办法；实验须符合用户权限与适用伦理，观察研究则逐项说明识别假设。
4. 检查替代解释、干预执行偏差及结论对假设的依赖；证据不足时仅报告关联并提出下一步验证。

**可检查产物：**因果问题定义、设计与假设表、主要指标、对照逻辑、效应估计或“无法识别”的说明。

**适用局限：**一次前后变化、个人感受或复杂模型都不足以单独证明因果。个人习惯实验可能受时间趋势、学习效应和同时变化的因素影响，不把个体结果直接推广到所有人。

## M05｜决策理论

**覆盖子概念：**期望效用、风险厌恶、信息价值、决策树、多准则决策、敏感性分析；机会成本、不可逆性、可保留的未来选择与后悔。

**何时调用：**所有决策；重点用于职业、学习、项目、居住和其他有明显机会成本或长期影响的选择。

**需要的输入：**用户目标与价值排序、现实选项、硬约束、时间跨度、风险承受边界、相关证据、可能情景，以及尚未确定的偏好。

**操作：**
1. 明确目标、硬约束和不可接受的后果，列出可行选项，必要时加入暂缓、维持现状或小规模尝试。
2. 比较各情景下的收益、代价、机会成本、可逆性和他人影响；概率有依据才估算，无依据则用明确标注的情景。
3. 只有在量纲和偏好可解释时使用效用或多准则评分；先筛选硬约束，再检查权重、概率和成本变化是否改变建议。
4. 给出当前建议、最强反对理由、改变建议的条件；比较先补信息与立即行动的价值，设计下一步和复盘点。

**可检查产物：**选项比较、约束检查、主要情景、敏感性或转折条件、建议依据、行动与复盘指标。

**适用局限：**期望收益不能代替用户的价值选择，也不能忽略承受不起的损失。主观权重不是客观事实；不同准则可能重复计分。没有可靠概率时，不虚构“成功率”来完成表格。

## M06｜运筹学

**覆盖子概念：**线性规划、整数规划、资源配置、排队、调度、网络流、多目标优化；目标函数、约束、可行解、最优解与启发式方案。

**何时调用：**任务之间争夺时间、预算、人力或设备，需要排班、安排学习、选择项目组合或设计服务流程时。

**需要的输入：**资源总量、任务依赖、耗时与成本范围、容量、截止条件、不可违反的限制、目标优先级；排队问题还需到达与服务过程数据。

**操作：**
1. 定义决策变量、资源与硬约束，把用户目标转成可解释的目标函数或优先级。
2. 先检查问题是否可行；选择足够简单的规则、线性／整数模型、网络模型或适用的排队模型。
3. 用实际工具求解或构造方案，明确结果是最优解、近似解还是启发式安排；检查是否违反任何现实约束。
4. 对任务超时、资源减少和优先级变化做压力检查，保留适当缓冲与调整空间。

**可检查产物：**变量和约束表、资源分配或时间表、求解状态、未满足需求、缓冲及调整规则。

**适用局限：**被优化的指标可能偏离真实目标。耗时估计错误、任务切换、疲劳和突发事件会破坏纸面最优；排队模型的到达、服务和稳定性假设需要核对，不能默认每天高负荷仍可持续。

## M07｜博弈论

**覆盖子概念：**策略、收益、最佳反应、纳什均衡、重复博弈、信息不对称、信号与承诺；激励相容、合作与可信约定。

**何时调用：**合作、谈判、竞争、分工或规则设计中，结果会受到其他参与者主动回应的影响时。

**需要的输入：**参与者、可选行动、各方已知利益与限制、信息分布、行动顺序、未来是否继续往来、已有约定及证据。

**操作：**
1. 分开已确认的利益、对动机的假设与完全未知的信息，列出各方真实可采取的行动。
2. 推演几种合理回应与最佳反应；有充分依据时才构造收益矩阵，注明收益是否只是排序。
3. 检查一次性与重复互动、信号可信度、承诺可执行性和违约诱因，寻找互利调整或可核验的约定。
4. 比较合作方案及破裂后的备选路径，记录需要向对方澄清的问题和改变判断的反馈。

**可检查产物：**参与者—利益—信息表、回应情景、合作条件、承诺机制和谈判备选方案。

**适用局限：**不能假定他人完全理性或已知其收益；均衡不代表公平、最优或一定发生。理论推演不能代替直接沟通，不采用欺骗、胁迫或利用他人脆弱性的方案。

## M08｜微观经济学与宏观经济学

**覆盖子概念：**供需、边际成本、机会成本、激励、外部性、交易成本、委托代理、逆向选择、道德风险；通货膨胀、就业、利率、货币、财政和经济周期。

**何时调用：**评价商业机会、定价、收入来源、岗位与行业选择，或分析经济环境对个人计划的影响时。

**需要的输入：**市场与地区、价格成本、需求证据、竞争和替代品、合同与激励安排、相关经济数据的日期及口径。

**操作：**
1. 分开个人或企业可影响的微观变量与外部宏观条件，核对需求、成本和替代选择。
2. 分析边际变化、机会成本、交易成本以及信息和代理问题，说明各参与者的激励。
3. 对关键外部变量采用有来源的情景，分析它们通过什么机制影响用户；区分名义金额与实际购买力。
4. 用小规模需求验证、合同调整或资源试配检验关键商业假设，再更新选择。

**可检查产物：**需求和成本证据、激励结构、单位经济性或现金影响、外部情景与验证计划。

**适用局限：**宏观叙事不能直接推出个体收益或资产价格方向；经济周期不是精确时钟。模型结论依赖市场结构和制度条件，应与 M09、M11 或其他解释比较，而非将某一种理论当万能答案。

## M09｜马克思主义政治经济学

**覆盖子概念：**生产力与生产关系、资本、劳动、价值与剩余价值、积累、分配、利益结构、社会再生产及历史条件；与其他经济解释的比较。

**何时调用：**分析劳动与资本关系、组织中的分配与控制、产业变化、利益冲突，以及个体选择受到的结构性影响时。

**需要的输入：**实际生产和组织关系、资源与控制权、劳动过程、收入分配、制度与历史材料，以及要解释的具体结果。

**操作：**
1. 先描述谁投入资源、谁劳动、谁承担风险、谁控制决策、收益怎样分配，避免先套结论。
2. 明确使用的理论概念与原文语境，区分概念分析、可检验的经验主张和规范性评价。
3. 对照现实材料解释关系与利益，比较微观激励、制度或其他理论是否能更好解释同一现象，并寻找不符合预期的证据。
4. 提取对用户选择真正相关的限制、机会和待调查问题，标明结论适用的历史与制度条件。

**可检查产物：**生产与分配关系图表、概念—材料对应、竞争解释、适用条件和具体行动含义。

**适用局限：**理论术语不是事实证据；群体结构不能直接证明某个人的动机。不能仅凭身份标签推导个人品格、政治立场或行为，也不把宏观理论直接当作个人职业或投资预测器。

## M10｜心理学与行为科学

**覆盖子概念：**认知心理学、社会心理学、行为经济学、人格心理学；注意、记忆、情绪、动机、习惯；确认偏误、锚定、损失厌恶、从众、群体极化、权威服从、关系依恋与冲突机制。

**何时调用：**拖延、习惯变化、情绪影响判断、沟通冲突、群体压力或用户希望了解自己的行为模式时。

**需要的输入：**具体情境与可观察行为、发生频率、当时条件、用户自述感受、已有尝试及结果；只取得与问题有关的信息。

**操作：**
1. 把“我不自律”“他有恶意”等总括评价改写为具体事件，分开观察与对内在动机的解释。
2. 列出认知、情绪、激励和环境等竞争解释，检查是否存在基准忽视、确认偏误或损失厌恶等影响。
3. 选择成本低、可逆的环境或行为调整，预先定义可观察指标；需要时先通过沟通核对他人的实际感受。
4. 根据一段时间的记录判断是否有改善；没有改善则修正假设，不归咎于人格缺陷。

**可检查产物：**情境—行为—后果记录、竞争解释、行为实验、反馈与调整建议。

**适用局限：**不能从聊天片段诊断疾病、依恋类型或稳定人格；心理效应存在情境、个体和研究质量差异。涉及持续显著困扰或功能受损时，明确专业评估的价值；不以常识性建议代替治疗。

## M11｜社会学、政治学、制度分析与组织行为

**覆盖子概念：**家庭、阶层、组织、官僚体系、权力、合法性、正式规则、非正式规则、群体身份、组织惯性、制度激励、协作与组织行为。

**何时调用：**个人努力与组织结果不一致、流程受阻、岗位或团队选择、跨部门协作、制度变更和利益协调时。

**需要的输入：**组织或社会情境、正式流程、实际运作记录、角色权限、考核激励、资源分配、具体事件与相关规则来源。

**操作：**
1. 区分个人行为、团队流程、组织结构和外部制度等层次，定位实际发生问题的位置。
2. 对照正式规定与实际执行，梳理决策权、资源权、责任、利益和非正式协作关系。
3. 比较个体动机、制度激励、信息断点与组织惯性的解释，列出需要核对的例外和反证。
4. 选择用户权限内的流程、信息或协作改进，明确需要谁参与、通过什么程序及如何观察效果。

**可检查产物：**角色—权限—激励表、流程阻点、解释与证据、可执行改进及参与条件。

**适用局限：**不能由职位或群体身份直接推断私人动机；结构解释不能替代具体事实或免除个人责任。政治制度的描述、法律效力和价值评价应分别陈述，并核对地区和时间。

## M12｜历史与思想史

**覆盖子概念：**中国史、世界史、中国近现代史、经济史、科技史、思想史；长期积累、路径依赖、周期变化、偶然事件、历史语境与史料辨析。

**何时调用：**需要理解制度、行业或思想的形成过程，使用历史类比，或判断“过去发生过，所以未来也会如此”的主张时。

**需要的输入：**待解释的问题、时期和地域、原始史料与可靠研究、来源形成背景、当前案例的具体条件。

**操作：**
1. 建立最小必要时间线，区分当时人的材料、后来的研究和当代转述，核对关键事件与概念含义。
2. 分析长期条件、路径依赖、行动者选择与偶然事件的作用，保留历史解释中的争议。
3. 做历史类比时并列共同机制和关键差异，检查是否只选择了符合结论的成功或失败案例。
4. 将历史分析转成今天需要留意的条件和问题，不直接当作未来必然结果。

**可检查产物：**带来源的时间线、史料与解释区分、类比适用表、争议和现实启示。

**适用局限：**历史资料可能不完整且存在视角偏差；“周期”和“规律”必须说明证据与范围，不能凭叙事预测具体时间点，也不能把后见之明当作当时可得的知识。

## M13｜毛泽东思想中的调查研究、实践与矛盾分析

**覆盖子概念：**调查研究、实事求是、《实践论》、矛盾分析、主要矛盾、战略与战术、群众路线、阶段性目标；与具体历史条件和现代科学方法结合。

**何时调用：**问题描述笼统、缺少一线情况、多种矛盾交织、资源有限需要识别阶段重点，或行动需要持续检验时。

**需要的输入：**实际问题、相关原文及历史语境、不同参与者的一手情况、限制条件、阶段目标、已有实践与反馈。

**操作：**
1. 从具体问题出发调查，收集不同位置的参与者与反例，记录材料如何取得及可能漏掉谁。
2. 列出相互关联的冲突和限制，提出当前主要问题的候选解释，用事实说明为何优先处理它。
3. 区分长期方向与当前行动，制定阶段目标和可逆试行，听取受到影响者的真实反馈。
4. 对照实践结果修正认识；条件变化时重新判断重点，保留当时依据和修正理由。

**可检查产物：**调查记录、主要问题及其证据、阶段目标、试行方案和认识修正日志。

**适用局限：**“主要矛盾”是待证实的分析判断，不能用一句口号代替因果证据或忽略多目标。历史论述需保留语境；不能用理论替用户预设政治立场，也不把抽象冲突概念用于煽动对具体人的敌意。

## M14｜系统科学、控制论与钱学森系统工程

**覆盖子概念：**系统边界、层次、接口、存量流量、状态与测量、输入输出、反馈、延迟、扰动、稳定性、可达/可控、可观测和鲁棒性；区分工程控制论、系统工程、开放复杂巨系统与综合集成。

**何时调用：**局部改进引发其他问题、结果存在延迟、多个因素相互强化或抵消，以及管理长期目标与复杂项目时。

**需要的输入：**阶段和输入版本、目标与硬约束、边界与参与者、状态与代理指标、关系证据、结果延迟、环境扰动、行动权限和资源上限。

**操作：**
1. S1—S2明确整体目标，区分状态x、可干预输入u、观测y、扰动d和测量噪声v；关系逐条标证据或假设。
2. S3—S4比较干预与测量方式，检查资源、累积投入、延迟和局部优化副作用；数据充分才建立数值模型。
3. S5检查隐藏状态和反例，区分名义稳定、跟踪性能和不确定性中的表现；数学判据只用于满足前提的模型。
4. S6—S8给条件建议，在已有授权内有上限试行；区分采集与调整频率，按观察窗口及及时停止条件更新记录。

**可检查产物：**变量及来源表、反馈与延迟、干预/测量对应、资源与副作用检查、模型或定性情景、验证和更新计划。具体步骤见 [M14模块](模块/M14-系统与控制.md)，来源与已运行反例见 [钱学森系统方法专题](资料/钱学森系统方法专题.md)。

**适用局限：**负反馈不保证稳定，指标良好不证明内部状态良好；关系图不是因果证据，有限仿真不是鲁棒性证明。AI共识不等于独立专家或实证；人生类比不能变成可控性定理。原著未读部分与历史争议保留，不以权威姓名替代证据。

## M15｜计算机、数据处理与信息安全

**覆盖子概念：**Excel、SQL、Python、数据清洗、可视化、基础算法、数据库、网络、信息安全；数据结构、来源记录、权限、备份和可复现流程。

**何时调用：**分析表格、整理个人记录、处理大量文件、重复计算、建立工具或连接数据源时。

**需要的输入：**获授权的数据和范围、格式与字段说明、任务目标、现有环境、质量标准、保存与备份要求、隐私和访问限制。

**操作：**
1. 确认任务范围与数据含义，检查缺失、重复、日期和单位，保留原始记录及来源；敏感信息只使用必要部分。
2. 选择足够简单的表格、查询或程序，明确每一步转换，避免静默覆盖原始资料。
3. 以样本核对、汇总勾稽和必要测试验证输出；可视化注明单位、范围和分母，避免截轴或选择数据误导。
4. 保存可复现流程与结果，按任务需要备份并检查恢复路径；说明权限、外部传输和执行限制。

**可检查产物：**数据字典、清洗与查询记录、代码或公式、核对结果、可视化、保存位置及必要恢复说明。

**适用局限：**程序运行成功不等于业务含义正确；没有记录不等于零。不能绕过访问限制或擅自扩大采集范围；本地存储不代表模型处理完全离线，自动化权限不能仅靠 Markdown 隔离。

## M16｜机器学习、大模型与自动化

**覆盖子概念：**机器学习基本原理、大模型、搜索、阅读、写作、分析与编程辅助、自动化；训练与推理、泛化、数据泄漏、偏差、幻觉、隐私泄露、错误推断和流程监控。

**何时调用：**考虑把重复工作交给 AI、训练或评价模型、从材料抽取信息、生成内容，或接入自动任务时。

**需要的输入：**明确任务、真实样例、正确结果或评价办法、允许的错误成本、可用数据与工具、授权范围、数据保存要求。

**操作：**
1. 明确输入、输出和失败后果，先建立人工规则或简单模型基线，判断 AI 是否比现有办法有实际价值。
2. 选择提示、检索增强、工具流程或训练方法；分开材料内容与执行指令，按授权控制信息访问和外部动作。
3. 用未参与设计的代表性样例检验质量、遗漏、偏差、成本和隐私；涉及预测时防止训练测试泄漏并考虑时间或主体隔离。
4. 明确自动执行范围、必要人工检查、失败处理与监控指标；运行后用真实反馈更新，不把生成内容自行当作证据。

**可检查产物：**任务规范、基线、评价样例与结果、失败案例、权限和流程说明、运行反馈与修订记录。

**适用局限：**流畅、格式正确和多代理一致不代表事实准确。同模型自审或多个相似模型的意见不构成独立证据；知识库和提示词不会自动让模型完成专业训练。无法接入的工具、未执行的任务不得声称已完成。

## M17｜语言表达、沟通与谈判

**覆盖子概念：**阅读、写作、提问、倾听、演讲、谈判、说服、冲突处理、结构化表达；一句话、一页纸和完整报告；事实、判断、意见、建议及利益顾虑的区分。

**何时调用：**汇报、求职、合作提案、家庭协商、反馈、争议解决，或需要把复杂问题讲清楚时。

**需要的输入：**交流对象与场景、要达成的结果、已知利益和顾虑、事实材料、用户立场、关系与时间限制。

**操作：**
1. 明确听众需要作出的判断或行动，先复述对方的已知关切，将对其动机的猜测单独标出。
2. 组织核心主张、证据、局限和请求，按需要形成一句话、一页纸或完整版本，使用对方能理解的语言。
3. 谈判时分开立场与利益，明确底线、可交换条件和备选方案；模拟反对意见并准备诚实回应。
4. 用复述、具体问题或实际任务检查理解，记录约定、责任和后续动作；外发按用户授权执行。

**可检查产物：**面向具体对象的稿件、事实与意见标记、提问清单、谈判条件、对方理解或约定记录。

**适用局限：**表达清晰不代表内容真实；模拟不能保证真实对方接受。说服应建立在诚实和尊重自主选择的基础上，不编造背书、经历、证据或对方已认可的事项。

## M18｜管理与执行

**覆盖子概念：**目标设定、任务分解、优先级、项目管理、授权、反馈、会议、流程、组织协作、风险管理和复盘。

**何时调用：**目标长期停留在想法、任务很多但进展不清、多人协作、计划变化或需要稳定推进时。

**需要的输入：**用户认可的目标、完成标准、期限、资源与责任人、任务依赖、现有承诺、风险和过去执行记录。

**操作：**
1. 把目标转成可观察成果，分解关键依赖与下一步行动，区分用户承诺和 AI 建议。
2. 根据重要性、时限、依赖和资源安排优先级，预留缓冲；多人任务明确责任、决策权和交付标准。
3. 采用最低必要的反馈频率、会议和流程，记录阻碍、变化及实际完成证据，及时调整计划。
4. 复盘结果与过程，区分计划假设错误、执行偏差和外部变化，把改进落实到下一轮行动。

**可检查产物：**目标—行动关联、责任与完成标准、依赖和时间安排、进展证据、风险应对和复盘变更。

**适用局限：**不能将计划经过日期视为已经完成，也不能把忙碌时长当成成果。指标可能诱发凑数，记录系统的负担也要计入成本；休息与健康不应被无限加任务挤占。

## M19｜个人财务

**覆盖子概念：**收入、消费、预算、现金流、资产负债、复利、通货膨胀、保险、债券、股票、指数基金、资产配置、风险收益和常见骗局。

**何时调用：**评价收入中断承受力、工作转换、学习投入、大额支出、债务、保障或投资选择时。

**需要的输入：**用户愿意提供的必要收支区间、可动用资产、债务与期限、家庭责任、资金使用时间、风险承受条件；具体产品另需最新条款与费用。

**操作：**
1. 区分收入、利润、现金流和净资产，建立必要的收支与偿付概览，明确流动性和近期义务。
2. 对收入下降、支出增加和资金锁定做情景分析，检查重要责任是否仍能履行及最坏损失是否可承受。
3. 比较方案的总成本、期限、流动性、信用与市场风险、费用和适用条款；投资假设与预期收益必须有来源或明确标为情景。
4. 给出与目标和能力匹配的备选安排、需核实的条款和复盘条件，重大或复杂问题指出适当外部专业核实事项。

**可检查产物：**必要的现金流与负债摘要、风险情景、方案成本与限制、待核实条款和行动条件。

**适用局限：**不承诺收益，不将历史回报视为未来保证，不凭宏观故事给出确定价格预测。不预设统一应急金月数或资产比例适合所有人；法律、税务与产品信息须核对地区和日期，不收集完整账户凭证。

## M20｜法律基础

**覆盖子概念：**宪法、民法、合同、侵权、劳动、公司、刑法和行政法；权利、义务、证据、责任、程序、管辖与时效。

**何时调用：**签约、就业、合作、经营、数据使用、争议处理或重大行动可能产生明确法律后果时。

**需要的输入：**所在地区与适用法律、事件和日期、相关文本及材料、当事人角色、用户目的、可能截止期限。

**操作：**
1. 分清已发生事实、双方主张和未知事项，确定法律领域、地区、时间及可能紧迫的程序节点。
2. 查询现行官方法律与相关适用资料，核对效力、施行时间、主体与例外；区分法条内容和对个案的推断。
3. 按权利义务、证据、责任与程序整理可选路径，检查合同条款和现实行动是否存在关键遗漏。
4. 列出用户可先完成的资料整理及需要专业核实的问题；重要争议、复杂适用或不可逆行动保留专业评估环节。

**可检查产物：**事实时间线、适用规则及官方来源、证据清单、可选程序与期限、待核实法律问题。

**适用局限：**通用知识和文本摘要不能代替完整个案判断；地区、版本、事实细节和证据能力可能改变结论。不能将道德赞同当作合法性依据，或保证案件结果、合同有效及责任免除。

## M21｜健康基础

**覆盖子概念：**运动、力量训练、有氧能力、营养、睡眠、压力、成瘾、慢性病风险和医学证据；长期行动能力与生活质量。

**何时调用：**规划可持续作息与活动、判断健康信息、评估计划对身体的负担，或健康状况影响其他人生选择时。

**需要的输入：**用户提供的相关情况、目标、现有医嘱、活动限制、习惯与环境；只询问当前问题必需的信息。

**操作：**
1. 区分一般生活规划与症状、疾病或治疗问题；如有明显紧急线索，优先说明及时就医路径。
2. 查询适用人群的现行权威指南和证据，区分已确立建议、证据有限的主张和个体适用未知。
3. 在既有医嘱和实际条件内提出可执行、渐进的生活调整，明确观察指标与需要停止或寻求评估的条件。
4. 依据持续记录、用户反馈与必要专业意见调整，兼顾休息、生活质量与长期可持续性。

**可检查产物：**证据来源及适用范围、具体生活调整、观察与停止条件、需要就医或核实的问题。

**适用局限：**不能用聊天或生活记录作确定诊断，不能以科普替代检查和治疗。群体建议不一定适合特定疾病、用药或身体状态；不能将缺乏证据的因果说法、食物功效或单一指标包装成医疗结论。

## M22｜英语与原始资料检索

**覆盖子概念：**英文关键词检索、教材、论文、技术文档、公开课；阅读与听力、术语、翻译、原始资料与可靠来源核对。

**何时调用：**中文转述不足、需要一手知识、验证术语与方法细节、学习技术或阅读研究材料时。

**需要的输入：**明确问题、已有中文与英文关键词、所需资料类型、可访问范围、日期要求和用户语言水平。

**操作：**
1. 把问题拆成核心术语、同义词与限定条件，设计中英文检索式，优先寻找直接相关的原始或权威资料。
2. 核对作者或机构、发布日期、版本、研究或文档范围，记录是否取得正文；打不开时保留访问状态，不编造内容。
3. 提取直接相关段落、方法与限制，核对否定、条件、概率词和专有名词，给出保留原意的中文解释。
4. 将主张与出处对应，重要歧义查看上下文或其他可靠来源；形成能复用的关键词和必要术语表。

**可检查产物：**检索式、来源及访问状态、主张—出处对应、关键术语对照、翻译疑点与下一步。

**适用局限：**英文材料不天然优于中文材料，官方资料也需检查其支持范围。搜索摘要、自动翻译、标题和模型记忆不能代替正文；无访问权限时不绕过限制，也不声称已经读完。

## M23｜文学、艺术、音乐、美学与伦理

**覆盖子概念：**文学、艺术、音乐、美学、伦理学；情感、尊严、悲剧、欲望、意义、审美、价值冲突；效率、结果、权利、责任、关怀与自主选择。

**何时调用：**伦理与价值部分用于所有决策；文学艺术音乐与美学在理解复杂经验、表达情感、选择生活方式、创作或审美判断时按需调用。

**需要的输入：**用户实际重视的事、不愿牺牲的边界、受影响者、相关作品或具体情境、文化背景及尚未澄清的价值冲突。

**操作：**
1. 明确选择服务于谁的什么目标，检查自主、尊严、权利、责任、关怀和公平是否受到影响；不替用户预设人生意义。
2. 从后果、义务与权利、关系责任等不同角度检视冲突，区分不可交换的边界与可协商的偏好，说明仍无法兼顾之处。
3. 需要文学艺术视角时，结合具体作品、体验或创作比较不同人物立场、情感和形式，区分个人审美、作品分析与事实主张。
4. 回到具体选择，说明效率之外的代价、值得保留的生活内容和用户需要亲自作出的价值取舍。

**可检查产物：**价值与受影响者说明、伦理边界检查、尚存冲突、用户取舍依据；按任务需要附作品分析、表达草稿或审美比较。

**适用局限：**伦理分歧不能仅靠数据或统一分数解决；文学人物和作品不能充当现实心理或社会规律的实验证据。AI 能辅助理解与表达，不能把生成的共情描述冒充亲身经验或替用户决定什么人生值得过。

## 组合调用与复盘

以下仅是方法路由示例，不代表用户已经作出相应决定，也不代表固定模板适合所有人。

| 问题类型 | 基础调用 | 常见附加调用 | 首要检查产物 |
| --- | --- | --- | --- |
| 选择学习方向 | M01、M05、M23 伦理 | M18、M10、M22；涉及明显预算再用 M19 | 目标与约束、可检验能力成果、小规模学习试行 |
| 换工作或开始项目 | M01、M05、M23 伦理 | M08、M11、M17、M18、M19、M20 | 真实选项、需求或岗位证据、现金流边界、退出条件 |

| 改善合作与沟通 | M01、M05、M23 伦理 | M07、M10、M11、M17 | 已知利益与未知、回应情景、诚实提案、可核验约定 |

重要决策复盘须保留当时的信息状态、预测、选择与理由，再追加实际结果；区分判断错误、执行偏差和偶然变化。不能只凭一次好结果证明方法正确，也不能因一次坏结果就认定合理决策必然错误。需要调整方法时，注明修改原因与影响，避免重写历史来显得一直正确。
