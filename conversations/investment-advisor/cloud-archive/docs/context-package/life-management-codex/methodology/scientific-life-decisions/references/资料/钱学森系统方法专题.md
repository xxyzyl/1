## 先区分三条线

| 方向 | 本专题关注的问题 | 本次达到的阅读范围 |
| --- | --- | --- |
| 工程控制论 | 动态系统如何反馈调节；稳定、测量、干预与性能的关系 | 1954年《Engineering Cybernetics》书目和同期介绍；数学内容另读现代MIT原始教材相关节。未取得钱学森原著全书 |
| 系统工程 | 整体目标与分系统如何组织协调、验证和运行 | 核实1978年《组织管理的技术——系统工程》的发表背景和机构所引定义；未取得原文全文。下文接口、约束和验收流程是本项目的操作化设计 |
| 开放复杂巨系统与综合集成 | 开放、多层次且机制不全清楚的问题，如何结合资料、人的知识和计算逐步认识 | 读完《再谈开放的复杂巨系统》高校转载正文及注释；1990年合著文章只核实部分书目，未取得正文 |

## 从作者原文中保留什么

QX03强调开放交换、子系统多样、层次与未知机制；从具体材料与案例出发，将人的知识、资料及计算结合，再根据实践修正。专家意见仍可能不全面。这些主张可帮助组织调查和模型迭代；不意味着一切复杂问题都只有一种解法。

文中涉及人体特异功能、常温核聚变以及当时人工智能能力的断言，只作历史材料，不据此形成当代医疗、物理或AI能力结论。哲学立场与可验证经验命题分开。不要把当时对还原论或复杂性的分类直接写成现代数学定理。

以下S1—S8流程、证据分级、AI独立性要求和小规模试行方案，都是本项目的现代整理，不能写成钱学森逐字提出的标准操作程序。

## 沿决策流程使用

| 阶段 | 系统方法要回答的问题 | 可核查产物 |
| --- | --- | --- |
| S1 定义 | 改善哪个整体结果？边界外还有谁？局部优化会损害什么？ | 目标、期限、参与者、资源与价值底线 |
| S2 证据 | 实际状态是什么？测到的是什么？哪些环节未知？ | x/u/y/d/v变量表，来源、单位、采样频率；每条关系的证据或假设 |
| S3 方案 | 哪个位置能干预？改善测量或协调接口能否成为备选？ | 含保持现状的行动集、作用机制、负责人、测量方式及效果延迟 |
| S4 比较 | 在资源、延迟和环境变化下，各方案会怎样？ | 先硬约束后比较；有依据的情景、幅度上限、反转条件；必要时计算 |
| S5 复核 | 指标改善是否掩盖损害？模型错一点会怎样？ | 隐藏状态、替代解释、模型边界、外部反应及最强反例 |
| S6 建议 | 哪个方案在什么条件下值得试？用户实际选择了什么？ | 条件建议、剩余未知与真实选择状态，保留用户价值判断 |
| S7 行动 | 谁在已有授权内改变什么？如何及时发现副作用？ | 有上限的试行、基线、记录方式、观察窗口、停止条件 |
| S8 更新 | 观察差异来自测量、机制、执行还是环境？ | 预期与结果对照、证据更新、新输入版本及需要重做的比较 |

### 变量和模型要足够诚实

- x是实际状态；y是测量及代理指标。例如“能否独立完成任务”与“学习时长”不能互相替代。能力可以先定义为可检验表现，不强行捏造一个综合分数。
- u只包括用户确有权限实施的行动；他人的选择、市场价格与制度变化通常属于环境或其他自主行动者。对人的目标、同意与尊严检查仍由M23贯穿。
- d是环境变化，v是测量误差；数据少时可能分不清，两种解释都留着。控制模型中的动态噪声与因果推断中的混杂不是同一个概念。
- 定性关系图用于检查遗漏；参数无依据时不画看似精确的收益曲线。数值模型须记录方程、单位、初值、参数来源、校验资料与有效范围。
- 若使用资料、访谈、专家判断和计算结果，分别标明来源与角色。真实领域专家可能也有偏见；多名AI读取同一网页得出相同结论，只算同源推断。

### 反馈要考虑时间和资源

高频记录不等于高频改变策略。先估相关延迟和观察窗口，记录已经投入、尚未见效的行动；在结果出现前连续加码可能造成超量。设定累计预算、单次改变幅度、触发条件和退出方式，不假设“发现误差就无限补偿”可行。

观察窗口并非越长越好，也不要求所有行动都等到下一次复盘：明确有害或越过硬约束的信号应及时处理；对正常噪声或尚未成熟的结果则避免仓促归因。投入上限与等待时间须由任务事实确定，没有通用的最佳比例或周期。

记录效果不自动证明因果。试行同时发生其他变化、样本很少或只选择成功片段时，调用M04检查；M14的反馈循环不能替代实验设计。

## 数学结论的使用边界

对已指定、有限维、线性时不变模型，写清连续或离散时间。以下都是模型内结论；零输入内部稳定不保证跟踪精度、输入受限可行性或真实环境中的可靠表现。

| 问题 | 有条件的数学结论 | 不能推出什么 |
| --- | --- | --- |
| 连续时间内部渐近稳定 | 对ẋ=Ax，所有特征值实部严格小于0；依据QX05 | 不保证模型失配、饱和或外部扰动下仍满足目标 |
| 离散时间内部渐近稳定 | 对x[t+1]=Ax[t]，所有特征值模严格小于1；依据QX05 | 单位圆上的特征值需另分析，不能全称发散或渐近稳定 |
| 离散LTI可达 | 对x[t+1]=Ax[t]+Bu[t]，R=[B,AB,…,A^(n−1)B]满秩n；依据QX07 | 这是输入不受限时的状态可达性，不能保证给定预算/期限下可行；“可控到原点”在A奇异时可能不同 |
| LTI可观测 | 对y[t]=Cx[t]且模型与输入已知，O按C、CA、…、CA^(n−1)纵向堆叠且秩为n；依据QX08 | 不保证有噪声时准确重建，不等于“指标很多”；非零已知D项可扣除 |
| 鲁棒性 | 在明确的不确定性集合下分析保证是否成立；QX06区分名义与鲁棒稳定/性能 | 若只测试几个情景，只报告测试范围，不能称已证明所有情况稳健 |

稳定性分析只查看一个输出可能漏掉内部不稳定模态。输入输出表现良好与所有内部状态良好不是同一句话；下面第二个算例专门检验此差别。

## 两个已运行的原创教学算例

运行 `python3 scripts/system_control_examples.py --self-test`。只需Python标准库；本例有理数递推与解析表达式相互核对，无个人数据、无外部动作。这里的参数是人为指定，不是对某个人的估计。

### 例1：同样的纠偏力度，增加延迟会改变稳定性

设x[t+1]=x[t]+u[t]、目标0、x[-1]=x[0]=1，无噪声、无输入上限。

无延迟u[t]=−k·x[t]，闭环极点1−k。延迟一步u[t]=−k·x[t−1]，扩展状态矩阵为[[1,−k],[1,0]]，特征方程λ²−λ+k=0。由给定方程直接推导，再按QX05的离散判据分类。

| 延迟步数 | k | 最大极点模 | 分类 | 40步时x |
| --- | ---: | ---: | --- | ---: |
| 0 | 0.5 | 0.5 | 渐近稳定 | 约9.095×10^-13 |
| 0 | 1.5 | 0.5 | 渐近稳定，交替趋近 | 约9.095×10^-13 |
| 1 | 0.5 | 约0.7071 | 渐近稳定 | 约9.537×10^-7 |
| 1 | 1 | 1 | 本例周期振荡、有界、不趋近0 | 0，但后续仍振荡 |
| 1 | 1.5 | 约1.2247 | 不稳定 | 约−4136.93 |

一个时点恰好为0不能证明收敛；有限次仿真不是稳定性证明，分类依据特征方程。这说明“采用负反馈”本身不足以保证稳定。它不证明现实学习系统具有这些参数，也不直接给出个人的最佳调整频率。

### 例2：观测一直正常，内部问题仍可能增长

指定A=diag(0.8,1.1)，B=(1,0)ᵀ，C=(1,0)。R与O的秩均为1，小于状态维数2。取x[0]=(0,1)ᵀ、u恒为0，则所有y[t]=0，但隐藏的第二状态为1.1^t，40步约45.2593；该输入无法改变第二状态。

改为B=(1,1)ᵀ、C=(1,1)后，两个矩阵秩均为2；说明测量和行动的结构重要。这里只说明无噪声、已知模型、无输入限制下的秩性质，不承诺有限资源中的控制性能。生活应用只能提出“是否漏看重要状态、是否干预了有效位置”的调查问题，不能由类比断言某人系统必然失稳。
