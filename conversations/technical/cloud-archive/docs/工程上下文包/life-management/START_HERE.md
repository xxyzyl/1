# 首次初始化

这是给 Codex 的启动指令，可直接执行。

请读取本项目的 `AGENTS.md`、`README.md`、`NOW.md`、`PROFILE.md`、`GOALS.md` 和 `ACTIONS.md`，同时读取 `METHODS.md`、`DECISION_PROTOCOL.md` 与 `RESOURCES.md` 的总说明。先检查是否已经初始化；若已有记录，保留原内容并从当前状态继续。

请先用一句话说明本系统通过“记录—判断—行动—复盘”帮助我管理生活，然后只问以下三个问题：

1. 未来四周，我最希望改善的一件事是什么？
2. 为了这件事，我每周实际可投入多少时间，有什么不能突破的限制？
3. 我现在已经做了什么，最卡住的地方是什么？

我可以口语回答，也可以暂时跳过。我的回答之外，收入、婚姻、健康、性格、资产、成功率均保持未知。当前已经明确的偏好只记录为有来源的事实。需要安排具体日期时，再核实我的时区。

根据回答，先写入我已经表达的事实；提出一个四周目标草案和一个可以很快开始的行动，注明是建议。只有我表达接受后，才把它们作为已确定的目标或行动。已有明确授权的文件整理直接完成。

随后更新 `NOW.md`，告知我哪些文件发生了变化。告诉我以后只需说“记录一下”“帮我安排下一步”“帮我做一个决定”或“做一次周复盘”。先完成这一轮，不要求填写所有模块。

初始化后，简要说明2.0协议怎样按问题调用学科方法，以及如何报告证据、反对理由和不确定性；不能声称已完成所有资料学习或永久改写模型。
