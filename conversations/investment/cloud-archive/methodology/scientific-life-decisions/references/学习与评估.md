# 从资料到可检查的应用

版本：2.0。这里的“学习”指查阅资料、形成可保存的方法、应用和纠错；不会改变模型权重，也不声称获得永久学科资格。

## 每次补充能力的循环

1. **明确问题。** 写明希望解决的具体问题和知识缺口，查看 METHODS 的触发条件。先确认个人约束与目标，避免为使用某个模型而改变问题。
2. **阅读对应材料。** 从 RESOURCES 找到作者、大学、机构或官方原文，实际读取相关章节；记录网址、版本、查阅日期和阅读范围。目录只能确认范围，不能支持具体结论。需要最新事实时重新检索；检索失败如实记录。
3. **重建方法。** 用自己的话解释概念，列出输入、假设、步骤、输出、适用条件和失效情况；区分原文主张与本系统新增的操作规则。
4. **做一个例子。** 使用明确标为合成的数据或用户授权的真实数据。涉及影响决策的数字，实际用公式或代码计算，保留输入与结果。没有执行的计算、实验或测试不得写成已经执行。
5. **尝试反驳。** 给出最强的合理反对理由、替代解释或边界案例；说明什么证据会改变结论。价值问题讨论不同取舍，不能靠数据替用户确定价值。
6. **按风险复核。** 确认来源是否真的支持关键主张，必要时使用不同的数据、独立计算或专业审阅。模型再次回答或多个模型同意，均不自动构成独立验证。
7. **保存与纠错。** 将有依据的操作规则合并到 METHODS 的相应模块，将新来源和阅读状态加入 RESOURCES／RESEARCH。保留原判断、错误原因、修订内容和下次检查方式；真实决策另存 DECISIONS，实际结果追加到原记录。

## 状态用证据描述

| 状态 | 可以据实声明的内容 | 不可由此推断 |
| --- | --- | --- |
| 已核验入口 | 网站、作者归属、目录或课程范围已查看 | 全书已读、方法已掌握 |
| 已阅读相关正文 | 特定章节或段落已读，摘要有来源 | 全领域结论适用于当前用户 |
| 已做合成应用 | 指定输入和场景得到一个可检查结果 | 真实场景成功率或稳定熟练度 |
| 已作额外核对 | 有具体计算、资料对照或独立审阅记录 | 所有假设都真实或建议必然正确 |
| 已获得现实反馈 | 某次行动有结果和观察范围 | 结果一定由建议造成、以后可重复 |

不设置笼统的“已掌握23门学科”标记。每次使用某种方法都要满足该次任务的证据和适用条件，不能凭上次通过替代当前核验。

## 验证与更新

当前 Skill 的实测范围见 `验证记录.md`。这些检查不构成学科考试或人生决策准确率。发现影响结论的错误时修正对应模块、保留回归案例；更新 Skill 时使用 Skill Creator 的实际保存流程。
