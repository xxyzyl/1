# 模块路由

本表列M01—M23共享知识与方法。人生领域D01—D09另见 [领域清单](人生领域清单.json) 与 [总控架构](人生总控架构.md)：先定位受影响领域及全局约束，再选择本表的实际方法。比如学习转型可涉及D05/D04/D06，却不必同时启动所有领域或M角色。D角色提交需求与影响，总控协调共同预算和取舍。

流程入口为 `决策引擎.md`；先定位S1—S8的当前阶段，再选择本表的模块。知识、方法和执行工具可在任意相关阶段使用，不能把模块列表当工作顺序。

先按问题选方法，再分派独立工作。M01、M05、M23 的伦理检查由主协调者兜底；是否另起代理由复杂度和独立工作决定。所有23模块均有独立角色卡，但并非每次全部启动。

| ID | 角色 | 主要交付问题 |
| --- | --- | --- |
| [M01](模块/M01-逻辑与科学方法.md) | 逻辑与科学方法 | 所有决策；尤其是比较相互冲突的说法、检查宣传或专家意见、从少量经历推出一般结论时。 |
| [M02](模块/M02-基础数学.md) | 基础数学 | 需要表达数量关系、增长或衰减、复利、资源约束、比较量级，以及建立统计或优化模型时。 |
| [M03](模块/M03-概率与统计.md) | 概率与统计 | 从样本推断总体、比较风险和波动、更新判断、分析调查或行为记录、评价预测表现时。 |
| [M04](模块/M04-因果推断与实验.md) | 因果推断与实验 | 要判断培训、习惯、政策、营销或产品改动是否带来变化，或要依据观察数据决定采取某种干预时。 |
| [M05](模块/M05-决策理论.md) | 决策理论 | 所有决策；重点用于职业、学习、项目、居住和其他有明显机会成本或长期影响的选择。 |
| [M06](模块/M06-运筹与资源配置.md) | 运筹与资源配置 | 任务之间争夺时间、预算、人力或设备，需要排班、安排学习、选择项目组合或设计服务流程时。 |
| [M07](模块/M07-博弈与合作.md) | 博弈与合作 | 合作、谈判、竞争、分工或规则设计中，结果会受到其他参与者主动回应的影响时。 |
| [M08](模块/M08-微观与宏观经济.md) | 微观与宏观经济 | 评价商业机会、定价、收入来源、岗位与行业选择，或分析经济环境对个人计划的影响时。 |
| [M09](模块/M09-马克思主义政治经济学.md) | 马克思主义政治经济学 | 分析劳动与资本关系、组织中的分配与控制、产业变化、利益冲突，以及个体选择受到的结构性影响时。 |
| [M10](模块/M10-心理与行为.md) | 心理与行为 | 拖延、习惯变化、情绪影响判断、沟通冲突、群体压力或用户希望了解自己的行为模式时。 |
| [M11](模块/M11-社会制度与组织.md) | 社会制度与组织 | 个人努力与组织结果不一致、流程受阻、岗位或团队选择、跨部门协作、制度变更和利益协调时。 |
| [M12](模块/M12-历史与思想史.md) | 历史与思想史 | 需要理解制度、行业或思想的形成过程，使用历史类比，或判断“过去发生过，所以未来也会如此”的主张时。 |
| [M13](模块/M13-调查研究与实践.md) | 调查研究与实践 | 问题描述笼统、缺少一线情况、多种矛盾交织、资源有限需要识别阶段重点，或行动需要持续检验时。 |
| [M14](模块/M14-系统与控制.md) | 系统与控制 | 局部改进引发其他问题、结果存在延迟、多个因素相互强化或抵消，以及管理长期目标与复杂项目时。 |
| [M15](模块/M15-计算机数据与安全.md) | 计算机数据与安全 | 分析表格、整理个人记录、处理大量文件、重复计算、建立工具或连接数据源时。 |
| [M16](模块/M16-人工智能与自动化.md) | 人工智能与自动化 | 考虑把重复工作交给 AI、训练或评价模型、从材料抽取信息、生成内容，或接入自动任务时。 |
| [M17](模块/M17-表达沟通与谈判.md) | 表达沟通与谈判 | 汇报、求职、合作提案、家庭协商、反馈、争议解决，或需要把复杂问题讲清楚时。 |
| [M18](模块/M18-管理与执行.md) | 管理与执行 | 目标长期停留在想法、任务很多但进展不清、多人协作、计划变化或需要稳定推进时。 |
| [M19](模块/M19-个人财务.md) | 个人财务 | 评价收入中断承受力、工作转换、学习投入、大额支出、债务、保障或投资选择时。 |
| [M20](模块/M20-法律基础.md) | 法律基础 | 签约、就业、合作、经营、数据使用、争议处理或重大行动可能产生明确法律后果时。 |
| [M21](模块/M21-健康基础.md) | 健康基础 | 规划可持续作息与活动、判断健康信息、评估计划对身体的负担，或健康状况影响其他人生选择时。 |
| [M22](模块/M22-英语与原始资料检索.md) | 英语与原始资料检索 | 中文转述不足、需要一手知识、验证术语与方法细节、学习技术或阅读研究材料时。 |
| [M23](模块/M23-文学艺术与伦理.md) | 文学艺术与伦理 | 伦理与价值部分用于所有决策；文学艺术音乐与美学在理解复杂经验、表达情感、选择生活方式、创作或审美判断时按需调用。 |

## 常见组合

| 任务 | 常见追加模块 | 必须核对 |
| --- | --- | --- |
| 职业或行业选择 | M08、M11、M18、M19、M20；按需 M17、M22 | 具体行动、同地区/资历/时点/报酬口径、现实进入条件 |
| 学习与时间安排 | M06、M10、M18、M22 | 可用时间、可验收成果、疲劳与缓冲 |
| 合作与谈判 | M07、M10、M11、M17 | 已知利益和猜测分开、权限、真实可执行承诺 |
| 数据或AI工作流 | M15、M16、M18；按需 M02、M03、M04 | 原始数据、基线、泄漏、权限和错误代价 |
| 健康或财务问题 | M21 或 M19，按需 M03、M20 | 当前适用证据、个体条件、不可承受后果 |
| 社会历史和复杂系统 | 按需 M04、M08—M14、M22 | 理论与事实分开，竞争解释和历史语境 |

主协调者选择主模块，重复的数据检索只做一次。模块之间依赖输出时先后执行；不依赖时才能并行。角色卡的理论范围不等于模型专业资格。
