# 跨项目调用：可选的全局入口

这是一份配置说明，不是已经生效的全局规则。本包没有访问你的电脑，也没有改写模型权重。

先在自己的电脑确认人生管理项目的实际绝对路径，再按你使用的 Codex 客户端设置。官方支持的用户级 AGENTS 位置通常为 `~/.codex/AGENTS.md`；应合并现有内容，不覆盖其他工作规则。自定义 CODEX_HOME 等设置可能改变位置。

可合并如下规则，并将占位路径换成真实路径：

> 当我要求人生、学习、职业、个人资源或重要生活选择的分析时，读取「我的人生管理项目实际绝对路径」中的 AGENTS.md、NOW.md、PROFILE.md、METHODS.md 和 DECISION_PROTOCOL.md，再按需要读取资料索引。按2.0决策协议执行并报告依据、方法、未知及改变建议的条件。资料不可访问时明确说明当前未加载，先执行能完成的基础检查，不声称已经遵循完整本地协议。遵守实际文件权限，不能为读取资料绕过访问控制。除非我授权，不把其他项目的资料复制到人生管理项目中。

配置后启动新对话，核对实际加载情况，并用一件低影响问题检查方法、证据和记录结果。自报“已遵守”不是充分验证，仍需抽查源文件和产物。

如果其他项目的沙箱无法读取该路径，可以从人生管理项目启动任务，或通过客户端正式配置必要的只读访问；不要默认开放整个磁盘。网页或另一台电脑需要能访问同一套资料，账号相同不代表本地文件已同步。

来源：[OpenAI 官方 AGENTS.md 文档](https://learn.chatgpt.com/docs/agent-configuration/agents-md)。本入口是建议文本，没有安装为原生 Skill，也没有自动修改配置。
