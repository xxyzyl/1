# 下一步开发任务

## P0：先做出可演示纵向切片

- 建立 TypeScript ESM 项目、数据库迁移、环境变量加载和基础日志。
- 实现 Goal、Commitment、ResourceSnapshot、Decision、Option、Action、Feedback 表及版本字段。
- 实现资源核算纯函数：固定基线 + 唯一行动 + 缓冲；支持分钟、小时和金额单位校验。
- 实现 S1–S4 的输入、方案和比较接口，以及 S6–S8 的选择、执行和反馈状态。
- 完成单页对话输入和计划页：输入目标/10小时 → 显示冲突 → 展示 A/B/C → 选择 B → 修改为8小时 → 显示调整原因。
- 增加“模拟场景”标识和证据/未知展示。

## P1：可用性与数据安全

- 登录、用户时区、权限中间件、审计事件和幂等写入。
- 连接器抽象层，先接一种日历或任务来源；实现授权、同步、撤销、重连和错误提示。
- 数据导出、删除、来源纠正、同步时间和最小权限页面。
- 计划版本差异视图、暂停/停止条件和周复盘。
- 用真实目标用户进行 20 次访谈、10 人付费试点；记录付款、退款、复盘、人工分钟和结果。

## P2：AI 与产品化

- 结构化抽取 schema、工具调用白名单、事实/推断/假设分类和来源引用。
- 最少补问策略；用户修改结构化结果后保留原始输入和修订记录。
- 人工辅助与自动化交付的工时、模型、云和支持成本看板。
- 与“通用 AI + 表格/日历”做同口径对照；观察行动、成果和维护时间。

## P3：扩展与融资材料更新

- 根据首批用户证据决定阶段服务、订阅或混合收费。
- 再扩展财务、学习、关系等领域；不要先建设所有九领域。
- 更新融资PPT：补充真实团队履历、用户数据、收入/续费、成本和融资金额。
- 形成隐私政策、用户协议、数据处理清单和安全评估。
