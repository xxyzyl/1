# 人生管理系统 4.0

这是一个面向个人长期发展的“整体协调 · 科学决策 · 主动服务”系统。它把人生视为一个开放、动态、受资源约束并且存在反馈延迟的复杂系统，由用户确定价值与方向，由人生总控协调多个生活领域，由共享能力模块提供分析方法，由数据接入和反馈机制持续更新判断。

## 项目目标

系统不是简单的待办清单、习惯打卡器或人生评分器，而是帮助用户：

- 把模糊愿望转化为明确问题、目标、约束和可验证结果；
- 汇总日历、待办、文件、财务、健康和用户主动反馈等信息；
- 识别跨领域冲突，统一核算时间、资金、精力和承诺；
- 按八阶段决策流程生成带证据、假设、风险和反馈窗口的建议；
- 主动发现关键数据缺口，只询问会改变结论的问题；
- 跟踪建议执行后的结果，区分判断错误、执行偏差、环境变化和反馈延迟；
- 保留决策版本、证据来源和用户最终选择，形成可复盘的个人知识与行动系统。

## 产品定位

面向希望改善工作、学习、健康、财务、关系和生活安排的个人用户，第一阶段是“本地优先的个人决策与复盘工作台”；后续可以发展为带授权数据连接、主动问询、AI决策协作和隐私治理的个人长期管理产品。

核心原则：用户拥有价值判断和最终选择权；系统负责整理、分析、提醒、比较和反馈；建议不等于决定，记录缺失不等于事情没有发生，局部优化必须接受整体约束检查。

## 核心功能

1. 人生总控：维护目标、底线、当前状态、共同资源和跨领域影响。
2. 九个子系统：健康恢复、心理调节、关系家庭、职业价值创造、学习能力、财务保障、居住日常、社群责任、休闲审美。
3. 八阶段决策引擎：定义问题、建立事实、生成方案、约束比较、反驳复核、建议取舍、授权执行、反馈更新。
4. 二十三个共享能力模块：决策方法、知识与价值、信息与执行三类模块按需调用。
5. 主动服务循环：自动读取已授权来源，发现缺口，提出最少关键问题，生成建议，跟踪效果并复盘系统自身表现。
6. 数据与证据治理：记录来源、时间、置信状态、授权范围、同步状态、用户修正和版本关系。
7. 执行与复盘：把建议拆成行动、负责人、截止日期、验收证据、停止条件和观察窗口。
