# 上下文资料索引

本包根目录的六个文档是交给本地 Codex 的工程入口；`life-management/` 是当前可继续使用的文件型项目骨架。

## 已纳入的资料

- `life-control-4/人生管理系统4.0-完整设计.md`：4.0整体设计原稿。
- `life-management/`：决策协议、23模块方法、数据与领域定义、模板、示例、复盘和验证工具。
- `decision-flow/`：3.0八阶段决策流程图及 SVG/PNG源文件。
- `agent-collaboration/`：子智能体协作图、分段图和校验文件。
- `research_*.md`：系统工程、量化、社会历史和人生价值等研究笔记。
- `engine-evaluation-v3/`、`skill-evaluation/`、`validation_results.json`：已有评估与验证材料。
- `life-decision-design-preview.html`：已有决策设计预览。

## 版本与边界

4.0是整体架构；3.0是单次决策引擎。现有验证是结构和有限案例验证，不是长期真实用户效果验证。自动读取日历、待办、财务、健康或电脑操作尚未在本包中实现。
