# 上下文包清单

本压缩包包含：

- `README.md`：项目目标、定位、核心功能和当前进度
- `AGENTS.md`：本地 Codex 工作规则与禁止事项
- `SPEC.md`：需求、流程、数据结构和接口设想
- `ARCHITECTURE.md`：分层、模块、数据流和 MVP 边界
- `TODO.md`：按优先级排列的开发任务
- `.env.example`：环境变量模板
- `docs/CONTEXT.md`：历史设计、版本、来源、验证和商业化假设
- `人生管理系统4.0-完整设计与模块详解.pptx`：现有设计说明原件

说明：本包优先收录与继续开发直接相关的项目产出和上下文。其他聊天中的图片、演示图或未能取得本地字节的历史文件没有被伪造补入；如本地已有对应文件，应放入同一仓库并在 `docs/CONTEXT.md` 中登记。
